# Repo map: analysis

_554 files, leaf model `gemma-4-26b`, reduce model `gemma-4-26b`._

> This package implements a full semantic pipeline for Lua, ranging from AST walking and CFG construction to advanced lattice-based dataflow analysis. It provides the formal type systems, constraint solvers, and diagnostic engines required to produce actionable program insights and module signatures.
